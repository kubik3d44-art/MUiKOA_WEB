# MUiKOA_WEB

Веб-модуль учёта и контроля оборота авиационных агрегатов на складе авиакомпании.

Приложение предназначено для автоматизации работы сотрудников склада и связанных подразделений: ведения справочной информации, оформления складских документов, контроля движения и технического состояния агрегатов, формирования отчётности и управления доступом пользователей.

## Функциональные возможности

### Авторизация и разграничение доступа

* Авторизация пользователей по email и паролю.
* Разделение функциональности в зависимости от роли пользователя.
* Отдельные наборы доступных разделов и операций для различных категорий сотрудников.

### Работа со справочниками

* Просмотр справочной информации.
* Создание новых записей.
* Редактирование существующих записей.
* Обновление данных.
* Использование справочной информации при работе с документами и операциями.

### Учёт агрегатов

* Ведение каталога авиационных агрегатов различных типов.
* Работа с отдельными экземплярами агрегатов.
* Просмотр информации об агрегатах.
* Контроль текущего состояния и местонахождения агрегатов.

### Складские документы

* Создание и обработка складских документов.
* Регистрация операций с агрегатами.
* Фиксация изменений, связанных с движением агрегатов.
* Просмотр информации по оформленным документам.

### Контроль движения агрегатов

Модуль позволяет отслеживать историю перемещения каждого агрегата:

* дату движения;
* тип операции;
* предыдущее местонахождение;
* новое местонахождение;
* серийный номер;
* наименование агрегата;
* номер документа движения.

История может формироваться как для отдельного агрегата, так и для всех агрегатов.

### Контроль технического состояния

* Контроль технического состояния авиационных агрегатов.
* Контроль сроков эксплуатации.
* Фиксация установки агрегата на конкретное воздушное судно.
* Работа с информацией, необходимой инженеру для контроля состояния агрегатов.

### Отчётность и аналитика

* Формирование актуальной отчётности по складским операциям.
* Просмотр истории движения агрегатов.
* Получение аналитической информации для работы со складскими показателями.
* Поддержка формирования информации, используемой менеджером по снабжению при планировании закупок.

## Пользовательские роли

### Администратор

Администратор имеет полный доступ к функциям модуля и выполняет операции по его администрированию и управлению пользователями.

### Кладовщик

Кладовщику доступны основные складские функции:

* справочники;
* документы;
* движение агрегатов.

### Инженер

Инженер использует инструменты контроля технического состояния авиационных агрегатов.

### Менеджер по снабжению

Менеджер по снабжению получает доступ к:

* планированию закупок;
* аналитической отчётности по складу.

## Технологии

### Backend

* **C#** — основной язык программирования.
* **.NET** — платформа разработки приложения.
* **ASP.NET Core / Blazor Web App** — основа веб-приложения.
* **Razor Components** — реализация пользовательского интерфейса.
* **Controllers** — обработка запросов и реализация бизнес-логики.

Выбор C# обусловлен поддержкой объектно-ориентированного программирования, производительностью и тесной интеграцией с платформой .NET.

### Frontend

Пользовательский интерфейс реализован с использованием **Blazor Web App** и **Razor-компонентов**.

Интерфейс включает:

* страницу авторизации;
* пользовательскую панель;
* меню разделов;
* верхнюю панель команд;
* рабочую область;
* таблицы;
* формы;
* фильтры;
* карточки объектов;
* результаты запросов.

Основная работа пользователя осуществляется через единую рабочую область, в которой отображается функциональность, доступная его роли.

## Архитектура

Модуль реализован с разделением приложения на уровни представления и бизнес-логики.

**Уровень представления** отвечает за взаимодействие пользователя с системой и реализован на базе Blazor и Razor-компонентов.

**Уровень бизнес-логики** представлен контроллерами, которые:

* принимают запросы от пользовательского интерфейса;
* выполняют проверку данных;
* реализуют бизнес-правила;
* управляют транзакциями;
* формируют запросы;
* используют модели данных приложения.

Такое разделение позволяет отделить пользовательский интерфейс от обработки прикладной логики.

## Интерфейс

Интерфейс модуля адаптирован под различные категории пользователей. После авторизации состав доступных разделов определяется ролью пользователя.

Основное рабочее пространство включает навигационное меню, панель команд и область отображения данных. Пользователь может переходить между разделами, работать с формами и таблицами, применять фильтры и выполнять доступные операции.

## Основные сценарии работы

Типовой сценарий работы с модулем включает:

1. Авторизацию пользователя.
2. Определение доступных функций в соответствии с ролью.
3. Переход к необходимому разделу.
4. Работу со справочниками, документами или складскими операциями.
5. Просмотр и обработку информации.
6. Формирование отчётности или просмотр истории движения агрегатов.

## Статус проекта

Проект представляет собой разработанный веб-модуль для учёта и контроля оборота авиационных агрегатов на складе авиакомпании.
